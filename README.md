# 컨투어 값 판독기

컨투어(등고선/온도 분포) 이미지에서 클릭한 위치의 색상을 범례 구간 값으로 읽어주는 GUI 도구.

## 실행
```
pip install -r requirements.txt
python main.py
```

## 폴더 구성
```
main.py                  실행 진입점
contour_reader/
  gui.py                 GUI (캡처 이미지 표시, 클릭/호버 판독, 마커/라벨)
  legend.py              범례 모델 (색상 -> 값 구간, 범례 색상 추출)
  interpolate.py         인접 구간 경계 거리로 선형 보간 (소수 2자리)
  export.py              저장 이미지 합성 (라벨 포함, 흰 배경)
  capture.py             화면 캡처 + 드래그 영역 선택
  settings.py            설정 저장/불러오기
config/settings.json     마지막 입력값 자동 저장 (종료 시)
legacy/old_script.py     기존 스크립트
```

## 사용법
1. **화면 영역 캡처(F2)** → 창이 숨겨지고 전체 화면이 어두워짐 → 원하는 영역을 드래그 (ESC/우클릭 취소).
   원하는 순간에 맞추려면 *캡처 지연(초)* 을 설정. 파일 열기/클립보드 붙여넣기도 가능.
2. **최소/최대값**, 단위, 구간 수 입력. 색상은 기본값(첨부 이미지의 10단계 범례)이 지정되어 있으며,
   색상칸을 클릭해 수정하거나 **이미지에서 범례 추출**로 범례 색상 막대를 드래그해 자동 지정.
   **색상 목록 옆 입력칸**에 범례의 중간 경계값(예: 22.521, 19.538 …)을 직접 입력할 수 있습니다.
   비워 둔 경계는 입력된 값들 사이를 균등 보간하며, 값은 아래→위로 갈수록 커야 합니다.
3. 이미지 위에서 마우스를 움직이면 실시간으로 값 표시, **좌클릭**하면 마커(값 라벨)가 고정됨.
4. 최대 색상은 `≥ 372.5 (최대 375 이상)`, 최소 색상은 `≤ 352.5 (최소 350 이하)` 로 표시
   (옵션으로 끄면 일반 구간 `a ~ b` 로 표시).
5. 마커 라벨은 **드래그해서 원하는 위치로 이동**할 수 있고(연결선이 따라감), 마커/라벨을 클릭하면 선택됩니다.
   휠: 확대/축소, 우클릭 드래그: 이동, Backspace: 선택 마커 삭제.
6. **선형 보간 (소수 2자리)**: 클릭 지점과 같은 색 영역(검은 선은 통과)에 맞닿은 아래/위 구간 색을
   주변에서 찾아 각 경계까지의 거리 d_lo, d_hi 로 값을 계산합니다.
   `값 = 구간하한 + (구간상한 - 구간하한) × d_lo / (d_lo + d_hi)`
   - 경계 탐색 반경(px) 안에서 한쪽 경계를 못 찾으면 구간 중앙값을 `~363.75` 처럼 근사로 표시합니다.
   - 최대/최소 색(`≥`, `≤`)은 범례 밖 값도 같은 색이라 보간하지 않습니다.
   - 옵션을 끄면 구간(`a ~ b`)으로 표시합니다.
7. **이미지 저장**: 마커가 표시된 이미지가 흰 배경 PNG로 저장되며, 이미지 밖으로 옮긴 라벨까지
   잘리지 않도록 캔버스가 자동 확장됩니다. 결과 복사도 지원.

범례 색상이 아닌 곳(검은 선, 배경, 문자)은 "범례 색상 아님"으로 표시되며, 좌측 하단 **⚙ 판독 옵션**(눌러서 펼침)의
*색상 허용오차*와
*샘플 크기*로 조절할 수 있습니다.

**그림자/조명 보정**(0~100): 그림자로 어두워지거나 조명으로 밝아진 부분도 인식하도록, 밝기·채도 차이를
덜 반영하고 색상(Hue) 위주로 비교합니다. 0이면 기존 RGB 거리 방식입니다. 너무 어두운 영역이 선으로
무시되면 *검은색 무시* 임계값을 낮추세요.
