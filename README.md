# 컨투어 값 판독기

컨투어(등고선/온도 분포) 이미지에서 클릭한 위치의 색상을 범례 구간 값으로 읽어주는 GUI 도구.

## 실행
```
pip install -r requirements.txt
python main.py
```

## 폴더 구성
```
main.py                  실행 진입점
contour_reader/
  gui.py                 GUI (캡처 이미지 표시, 클릭/호버 판독, 마커)
  legend.py              범례 모델 (색상 -> 값 구간, 범례 색상 추출)
  capture.py             화면 캡처 + 드래그 영역 선택
  settings.py            설정 저장/불러오기
config/settings.json     마지막 입력값 자동 저장 (종료 시)
legacy/old_script.py     기존 스크립트
```

## 사용법
1. **화면 영역 캡처(F2)** → 창이 숨겨지고 전체 화면이 어두워짐 → 원하는 영역을 드래그 (ESC/우클릭 취소).
   원하는 순간에 맞추려면 *캡처 지연(초)* 을 설정. 파일 열기/클립보드 붙여넣기도 가능.
2. **최소/최대값**, 단위, 구간 수 입력. 색상은 기본값(첨부 이미지의 10단계 범례)이 지정되어 있으며,
   색상칸을 클릭해 수정하거나 **이미지에서 범례 추출**로 범례 색상 막대를 드래그해 자동 지정.
3. 이미지 위에서 마우스를 움직이면 실시간으로 값 표시, **좌클릭**하면 마커(값 라벨)가 고정됨.
4. 최대 색상은 `≥ 372.5 (최대 375 이상)`, 최소 색상은 `≤ 352.5 (최소 350 이하)` 로 표시
   (옵션으로 끄면 일반 구간 `a ~ b` 로 표시).
5. 휠: 확대/축소, 드래그/우클릭 드래그: 이동, Backspace: 마지막 마커 삭제, 결과 복사/이미지 저장 지원.

범례 색상이 아닌 곳(검은 선, 배경, 문자)은 "범례 색상 아님"으로 표시되며, *색상 허용오차*와
*샘플 크기*로 조절할 수 있습니다.
